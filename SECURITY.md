# Security policy

Security fixes are supported for the latest released minor version. The importer handles untrusted archives, so reports involving archive traversal, validation bypass, digest confusion, resource exhaustion, external fetching, or package-supplied code execution are especially important.

Do not open a public issue for an undisclosed vulnerability. Use the repository host's private vulnerability-reporting feature when enabled, or contact a maintainer through an established private channel. Include the affected version, a minimal non-sensitive reproducer, observed impact, and any proposed mitigation. Do not attach restricted VAO content.

Maintainers will acknowledge a usable report, assess scope, prepare regression coverage, and coordinate disclosure with the reporter. No response-time or bounty commitment is implied.
