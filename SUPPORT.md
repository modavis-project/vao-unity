# Support

Use issues for reproducible importer defects, Unity-version compatibility problems, and focused feature requests. Include the package version, Unity editor version, target platform, import mode, relevant diagnostics, and whether the carrier is shareable.

Before filing, run validation in the archive inspector and check the support matrix. Never publish a restricted carrier or confidential payload. For standard interpretation and VAO-authoring questions, consult the [VAO Standard repository](https://github.com/modavis-project/vao-standard) and provide a minimized synthetic carrier where possible.

Security reports must follow `SECURITY.md`. Private application development, tracker configuration, custom shaders, and proprietary renderer integration are outside the maintained support surface.
