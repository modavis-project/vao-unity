# Changelog

## 0.6.0-rc.1 — 2026-08-28

- First public release candidate of the Unity package for VAO 0.4.0.
- Validates the final published manifest, carrier, and materialization-receipt schemas and enforces the associated archive, semantic, profile, numerical, and deterministic-runtime rules.
- Imports complete metadata or selected verified payload groups, creates typed package assets and receipts, and supports transactional reimport with rollback.
- Provides sampled playback, MIDI 1.0/2.0 and SMF support, linked Playables animation, media and presentation workflows, tracker-neutral XR placement, and optional host integrations.
- Provides deterministic execution and position-aware PCM RIR/AES69-SOFA FIR convolution with explicit extension boundaries for specialized renderers.
